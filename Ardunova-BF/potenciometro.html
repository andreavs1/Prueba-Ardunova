🎛️ LED con potenciómetro

En este proyecto vamos a aprender a controlar el brillo de un LED utilizando un potenciómetro conectado a Arduino.

🟢 Nivel: Principiante

📋 ¿Qué vamos a aprender?

Vamos a aprender a leer el valor de un potenciómetro y utilizarlo para controlar la intensidad de luz de un LED.

🧰 Materiales

  • Arduino UNO
  • 1 LED
  • 1 resistencia de 220Ω
  • 1 potenciómetro de 10kΩ
  • Protoboard
  • Cables jumper
  • Cable USB

🔌 Conexiones

Conectá el LED al pin digital 9 de Arduino utilizando una resistencia de 220Ω.

Conectá el pin central del potenciómetro al pin analógico A0. Los otros dos pines se conectan a 5V y GND.

💻 Código

int led = 9;
int potenciometro = A0;

void setup() {
    pinMode(led, OUTPUT);
}

void loop() {

    int valor = analogRead(potenciometro);

    int brillo = map(valor, 0, 1023, 0, 255);

    analogWrite(led, brillo);
}

⚙️ ¿Cómo funciona?

Arduino lee el valor del potenciómetro mediante el pin A0. Ese valor se transforma en un rango adecuado para controlar el brillo del LED.

Al girar el potenciómetro, el LED cambia su intensidad: puede pasar de estar casi apagado a estar completamente encendido.

🎯 Resultado

Al girar el potenciómetro, podemos aumentar o disminuir el brillo del LED.
