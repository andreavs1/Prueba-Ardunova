⚙️ Servomotor con potenciómetro

En este proyecto vamos a controlar la posición de un servomotor utilizando un potenciómetro conectado a Arduino.

🟡 Nivel: Intermedio

📋 ¿Qué vamos a aprender?

Vamos a aprender a leer el valor de un potenciómetro y convertirlo en un ángulo para controlar el movimiento de un servomotor.

🧰 Materiales

  • Arduino UNO
  • 1 servomotor
  • 1 potenciómetro de 10kΩ
  • Protoboard
  • Cables jumper
  • Cable USB

🔌 Conexiones

Conectá el cable de señal del servomotor al pin digital 9. El cable de alimentación va a 5V y el cable de tierra a GND.

Conectá el pin central del potenciómetro al pin analógico A0. Los otros dos pines van a 5V y GND.

💻 Código

#include <Servo.h>

Servo servo;

int potenciometro = A0;

void setup() {
    servo.attach(9);
}

void loop() {

    int valor = analogRead(potenciometro);

    int angulo = map(valor, 0, 1023, 0, 180);

    servo.write(angulo);

    delay(15);
}

⚙️ ¿Cómo funciona?

Arduino lee el valor del potenciómetro, que puede variar entre 0 y 1023. Luego transforma ese valor en un ángulo entre 0° y 180°.

Cuando giramos el potenciómetro, el servomotor cambia su posición siguiendo el movimiento.

🎯 Resultado

Al girar el potenciómetro, el servomotor se mueve desde una posición hasta otra entre 0° y 180°.
