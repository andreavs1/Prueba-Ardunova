🤖 Robot que evita obstáculos

En este proyecto vamos a crear un robot capaz de detectar obstáculos y cambiar de dirección automáticamente para evitarlos.

🔴 Nivel: Avanzado

📋 ¿Qué vamos a aprender?

Vamos a aprender a utilizar un sensor ultrasónico para detectar objetos y controlar motores para que el robot pueda desplazarse.

🧰 Materiales

  • Arduino UNO
  • Sensor ultrasónico HC-SR04
  • 2 motores DC
  • Driver de motores L298N
  • Chasis para robot
  • 2 ruedas
  • 1 rueda loca
  • Batería o fuente adecuada
  • Cables jumper

🔌 Conexiones

Conectá el sensor ultrasónico HC-SR04 utilizando los pines 10 para Trig y 11 para Echo.

El driver L298N controla los dos motores. Los pines de control utilizados en este ejemplo son 5, 6, 7 y 8.

💻 Código

int trig = 10;
int echo = 11;

int motor1A = 5;
int motor1B = 6;

int motor2A = 7;
int motor2B = 8;

long duracion;
int distancia;

void setup() {

    pinMode(trig, OUTPUT);
    pinMode(echo, INPUT);

    pinMode(motor1A, OUTPUT);
    pinMode(motor1B, OUTPUT);

    pinMode(motor2A, OUTPUT);
    pinMode(motor2B, OUTPUT);

    Serial.begin(9600);
}

void loop() {

    digitalWrite(trig, LOW);
    delayMicroseconds(2);

    digitalWrite(trig, HIGH);
    delayMicroseconds(10);
    digitalWrite(trig, LOW);

    duracion = pulseIn(echo, HIGH);

    distancia = duracion * 0.034 / 2;

    Serial.println(distancia);

    if (distancia > 20) {

        avanzar();

    } else {

        detener();

        delay(300);

        girar();

        delay(500);
    }
}

void avanzar() {

    digitalWrite(motor1A, HIGH);
    digitalWrite(motor1B, LOW);

    digitalWrite(motor2A, HIGH);
    digitalWrite(motor2B, LOW);
}

void detener() {

    digitalWrite(motor1A, LOW);
    digitalWrite(motor1B, LOW);

    digitalWrite(motor2A, LOW);
    digitalWrite(motor2B, LOW);
}

void girar() {

    digitalWrite(motor1A, HIGH);
    digitalWrite(motor1B, LOW);

    digitalWrite(motor2A, LOW);
    digitalWrite(motor2B, HIGH);
}

⚙️ ¿Cómo funciona?

El sensor ultrasónico mide la distancia entre el robot y los objetos que tiene delante.

Si no encuentra un obstáculo cerca, el robot continúa avanzando. Cuando detecta un objeto a menos de 20 centímetros, se detiene y gira para intentar evitarlo.

🎯 Resultado

El robot puede desplazarse y detectar obstáculos automáticamente, cambiando de dirección cuando encuentra uno.
