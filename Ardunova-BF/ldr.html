💡 LDR y tres LEDs

En este proyecto vamos a utilizar un sensor LDR para detectar la cantidad de luz del ambiente y controlar tres LEDs.

🟢 Nivel: Principiante

📋 ¿Qué vamos a aprender?

Vamos a aprender cómo leer un sensor de luz y utilizar diferentes valores para encender LEDs según la cantidad de luz detectada.

🧰 Materiales

  • Arduino UNO
  • 1 sensor LDR
  • 3 LEDs
  • 3 resistencias de 220Ω
  • 1 resistencia de 10kΩ
  • Protoboard
  • Cables jumper
  • Cable USB

🔌 Conexiones

Conectá el LDR formando un divisor de tensión y llevá la lectura al pin analógico A0.

Conectá los tres LEDs a los pines digitales 8, 9 y 10, utilizando una resistencia de 220Ω para cada LED.

💻 Código

int ldr = A0;

int led1 = 8;
int led2 = 9;
int led3 = 10;

void setup() {

    pinMode(led1, OUTPUT);
    pinMode(led2, OUTPUT);
    pinMode(led3, OUTPUT);

    Serial.begin(9600);
}

void loop() {

    int luz = analogRead(ldr);

    Serial.println(luz);

    if (luz < 300) {

        digitalWrite(led1, HIGH);
        digitalWrite(led2, HIGH);
        digitalWrite(led3, HIGH);

    } else if (luz < 600) {

        digitalWrite(led1, HIGH);
        digitalWrite(led2, HIGH);
        digitalWrite(led3, LOW);

    } else {

        digitalWrite(led1, HIGH);
        digitalWrite(led2, LOW);
        digitalWrite(led3, LOW);
    }

    delay(100);
}

⚙️ ¿Cómo funciona?

El LDR cambia su resistencia dependiendo de la cantidad de luz que recibe. Arduino lee ese valor mediante el pin A0.

Según el nivel de luz detectado, Arduino enciende uno, dos o tres LEDs.

🎯 Resultado

Los LEDs cambian según la cantidad de luz que detecta el sensor LDR. De esta manera podemos crear un sistema sencillo de iluminación automática.
