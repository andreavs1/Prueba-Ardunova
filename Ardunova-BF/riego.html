🌱 Sistema de riego automático

En este proyecto vamos a crear un sistema que detecta si la tierra está seca y activa automáticamente una bomba de agua.

🟡 Nivel: Intermedio

📋 ¿Qué vamos a aprender?

Vamos a aprender a utilizar un sensor de humedad del suelo para controlar automáticamente un sistema de riego.

🧰 Materiales

  • Arduino UNO
  • Sensor de humedad del suelo
  • Módulo relé de 5V
  • Bomba de agua pequeña
  • Fuente de alimentación adecuada para la bomba
  • Manguera
  • Protoboard
  • Cables jumper
  • Cable USB

🔌 Conexiones

Conectá la salida analógica del sensor de humedad al pin A0 de Arduino. La alimentación del sensor va a 5V y GND.

Conectá la entrada de control del módulo relé al pin digital 7. La bomba debe conectarse al relé y a una fuente adecuada para su voltaje. No conectes una bomba directamente a un pin de Arduino.

💻 Código

int humedad = A0;
int rele = 7;

void setup() {

    pinMode(rele, OUTPUT);

    Serial.begin(9600);
}

void loop() {

    int valor = analogRead(humedad);

    Serial.println(valor);

    if (valor > 600) {
        digitalWrite(rele, HIGH);
    } else {
        digitalWrite(rele, LOW);
    }

    delay(1000);
}

⚙️ ¿Cómo funciona?

El sensor mide la humedad de la tierra y envía un valor a Arduino. Cuando la tierra está suficientemente seca, Arduino activa el relé y este permite que la bomba funcione.

Cuando la tierra vuelve a tener suficiente humedad, Arduino desactiva el relé y la bomba deja de funcionar.

🎯 Resultado

El sistema permite automatizar el riego de una planta según la humedad del suelo.
