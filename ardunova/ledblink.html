Parpadeo de LED (Blink)

El clásico "Hola Mundo" del hardware libre.

Explicación

Este proyecto sirve para aprender a controlar una salida digital de Arduino. El LED se enciende y se apaga automáticamente cada segundo.

Materiales

  • Arduino UNO
  • LED
  • Resistencia de 220Ω
  • Protoboard
  • Cables

Código

void setup() {
  // Se ejecuta una sola vez al iniciar Arduino
  pinMode(13, OUTPUT); // Configura el pin 13 como salida
}

void loop() {
  // Se repite continuamente
  digitalWrite(13, HIGH); // Enciende el LED
  delay(1000);            // Espera 1 segundo
  digitalWrite(13, LOW);  // Apaga el LED
  delay(1000);            // Espera 1 segundo
}

Paso a paso

Conexiones

1. Conectar la pata larga del LED al pin 13.
2. Conectar la pata corta a GND mediante una resistencia.

Software

3. Abrir Arduino IDE.
4. Copiar el código.
5. Seleccionar la placa Arduino UNO.

Carga

6. Cargar el programa.
7. Observar el LED.

Resultado esperado

El LED se prenderá y apagará cada segundo de forma continua.
